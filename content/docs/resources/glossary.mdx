---
title: Glossary
description: Key Greenloop terms in one place.
---

| Term | Meaning |
| --- | --- |
| **Org Admin** | The single initial user; configures the system and creates all other users. |
| **Accesswise** | The separate application used to create and manage users. |
| **Talkloop** | The integrated calling product used to call customers from activities. |
| **Branch** | A demographic grouping (e.g. a state) that contains facilities. |
| **Facility** | A physical warehouse where items are received. |
| **Category** | A high-level material group with a measurement type, operation type, and workflow. |
| **Subcategory** | A detailed item within a category; the basis for billing. |
| **Asset** | An item that can be refurbished and resold. |
| **Essential** | Mandatory equipment that must be on a truck before dispatch. |
| **Work Order** | A definition of what to collect from a customer and from where. |
| **BOL** | Bill of Lading; tracks a job from pickup through to invoicing. |
| **Route** | The set of locations a driver visits during a trip. |
| **Dispatch** | The Operations page (previously Routes) where routes are planned in the Board, Calendar, Classic, or Map view. |
| **Needs scheduling** | Work orders without a route that still need a date or route in Dispatch. |
| **Fleet** | The Operations page (previously Trucks) showing each truck's routes, load, and unavailability. |
| **Truck unavailability** | A period when a truck can't be used, with a reason such as Maintenance or Repair. |
| **Route conflict** | A route planned on a truck that is unavailable that day. |
| **BOL stage limit** | How long a BOL may stay in a stage before it shows as Due soon or Over limit. |
| **Over limit / Due soon / On track** | A BOL that has passed its stage limit, is inside the warning window, or is within the limit. |
| **Board view** | A view with one column per stage (BOLs) or per route (Dispatch). |
| **Loose** | Items with no packaging, so packaging must be provided. |
| **Packaged** | Items already stored in packaging. |
| **Drop-Off Item** | Packaging or materials delivered to the customer. |
| **Triage** | Processing bulk materials (e.g. Gaylords) to prepare for sorting. |
| **Sorting & Counting** | Separating and categorizing materials from triage. |
| **COR / COD** | Certificate of Recycling / Certificate of Destruction. |
| **Lead** | A potential contact at the first lifecycle stage, managed in Lead Management. |
| **Prospect** | A record at the Prospect stage; usually a promoted lead. |
| **Customer** | A record at the Customer stage; commercial or residential. |
| **Status (lifecycle)** | Lead, Prospect, Customer, Inactive, or Archived. |
| **Tag** | A configurable label added to a record. |
| **Opportunity** | A potential deal with a customer, with an estimated total and expected close date. |
| **Projected / Weighted amount** | An opportunity's entered value, and that value × its stage probability. |
| **Stale (opportunity)** | An opportunity flagged for review because it isn't moving. |
| **Going cold / Cold (lead)** | A lead with no activity nearing, or past, the limit set on its lead status. |
| **Follow-up** | A scheduled call or meeting with a lead. |
| **Saved view** | A personal, named set of list filters, tab, sort, and columns. |
| **Project** | A group of work orders for a customer, with its own pricing (project quote). |
| **Price Tier** | A set of prices per sub type, general (shared) or customer specific. |
| **Adjust prices** | Raising or lowering copied customer-specific prices by a percent or dollar amount. |
| **Price Tier Quote** | A proposal to apply a price tier to a customer, with effective and expiry dates. |
| **Customer consent** | The customer's acceptance of an approved quote, when required. |
| **Branch Base / National Contract** | Price modes for customer-specific pricing and projects. |
| **Walk-in BOL** | A BOL for items dropped off at a facility without a work order. |
| **Recurring work order** | A work order that repeats on a set schedule. Its parent's notes are copied to every occurrence. |
| **Merge Job** | Combining a duplicate (source) customer into a target customer. |
