Every user can view their own profile after signing in.

<UIPath items={["Avatar", "Account Settings", "My Account"]} />

Click your **avatar** (top right), then click **My Account**.

## Profile details

A profile shows: profile picture, name, email, username, title, phone number,
mobile number, **application roles**, and **facilities**.

<Callout type="info">
  **Application roles** show the user's role across connected applications — for
  example, *Greenloop: Admin*, *Accesswise: another role*.
</Callout>

<Callout type="warn">
  Only **Admin** and **Org Admin** can **edit** profiles.
</Callout>

## Security section

From the security section a user can manage:

- **Password** (change it)
- **Multi-factor authentication**
- **Active sessions**
