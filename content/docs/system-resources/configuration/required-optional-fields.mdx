<UIPath items={["Configuration", "Required/Optional Fields"]} />

This page decides which fields users **must** fill in when they create a
customer, a prospect, or a lead. It has three tabs: **Customer Fields**,
**Prospect Fields**, and **Lead Fields**.

<Screenshot src="/images/configuration/required-fields.jpg" alt="Required/Optional Fields" caption="① Customer / Prospect / Lead Fields tabs ② Optional / Required for each field" />

<Steps>
  <Step>
    ### Choose the tab
    Click **Customer Fields**, **Prospect Fields**, or **Lead Fields**.
  </Step>
  <Step>
    ### Set each field
    For each field in the **Name** column, click **Optional** or **Required**.
    The highlighted button is the current setting. Some address fields (such as
    **State** and **Zip Code**) also offer **Conditionally Required**.
  </Step>
</Steps>

<Callout type="info">
  Greyed-out rows (for example **Name** and **Parent customer**) can't be changed on this page.
  Required fields are marked with an asterisk (*) on the forms.
</Callout>
