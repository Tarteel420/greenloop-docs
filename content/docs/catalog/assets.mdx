Assets are items that can usually be **refurbished and resold**, for example
laptops or RAM.

<UIPath items={["Catalog", "Assets"]} />

<Screenshot src="/images/catalog/assets.jpg" alt="Assets list" caption="① New Asset ② Edit / Delete ③ Data Containing Device?" />

The list shows each asset's **Name** and whether it's a **Data Containing
Device?** (**Yes** / **No**). Use **Search** to find an asset.

## Add an asset

<Steps>
  <Step>
    ### Click New Asset
    Click **+ New Asset** under the list. A new row appears.
  </Step>
  <Step>
    ### Enter the details
    Type the **Asset name** (for example *laptops*) and set the **Data
    containing device** toggle (**Yes** / **No**).

    <Screenshot src="/images/catalog/asset-new.jpg" alt="New asset row" caption="① Asset name ② Data containing device ③ Save ✓ / Cancel ✕" />
  </Step>
  <Step>
    ### Save
    Click the green **✓** to save, or **✕** to cancel.
  </Step>
</Steps>

To change or remove an asset, use the **pencil** (edit) or **bin** (delete)
icon in the **Actions** column.
