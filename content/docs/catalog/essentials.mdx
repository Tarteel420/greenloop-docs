Essentials are the **mandatory equipment** that must be on a truck before
dispatch (for example a *Tool Kit* or *Hydraulic Jack*), so every truck is
properly equipped for field operations.

<UIPath items={["Catalog", "Essentials"]} />

<Screenshot src="/images/catalog/essentials.jpg" alt="Essentials list" caption="① Add ② Row menu" />

## Add an essential

<Steps>
  <Step>
    ### Click Add
    Click **+ Add** under the list. A new row appears.
  </Step>
  <Step>
    ### Enter the name and quantity
    Type the **Name** and set the **Quantity** required, using − / +.

    <Screenshot src="/images/catalog/essential-new.jpg" alt="New essential row" caption="① Name ② Quantity ③ Save ✓ / Cancel ✕" />
  </Step>
  <Step>
    ### Save
    Click the green **✓** to save, or **✕** to cancel.
  </Step>
</Steps>

Use **⋮** on a row for its actions, and **Search by name…** to find an item.

| Field | Description |
| --- | --- |
| Name | Equipment name, for example *Tool Kit* |
| Quantity | How many are required |

<Callout type="info">
  Essentials apply to [trucks](/docs/system-resources/trucks) used on
  [routes](/docs/operations/routes).
</Callout>
