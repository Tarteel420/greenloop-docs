The **Dashboard** opens when you sign in and greets you by name
(**Welcome back …**). It shows widgets that summarize your organization's
activity.

## Default widgets

| Widget | What it shows |
| --- | --- |
| **Customers** | Total number of customers. |
| **Pending Approvals** | Number of approvals waiting. See [Approvals](/docs/customer-management/approvals). |
| **Create Walk-in BOL** | Shortcut to start a walk-in BOL. See [Walk-in BOLs](/docs/operations/bols/walk-in-bols). |
| **Today's Pickup/Drop off** | Routes and locations planned for today. Use the dropdown to pick a facility. |
| **Walk-in Commercial BOLs / Walk-in Residential BOLs** | **Total** walk-in BOLs and how many were **Created by me**. |
| **BOL Status Breakdown** | BOLs by status: Waiting for Pickup, Pickup Completed, In Processing, Ready for Sign Off, Signed Off. |
| **Fleet Availability for Today** | Percentage of trucks available today and how many are in for maintenance/repair. |
| **Activities** | Your **Upcoming** and **Past** activities. |

## Customize your dashboard

<Steps>
  <Step>
    ### Rearrange widgets
    Drag a widget by the **drag handle** (⠿) next to its title.
  </Step>
  <Step>
    ### Remove a widget
    Click **⋮** on the widget, then click **Remove**.
  </Step>
  <Step>
    ### Add a widget
    Click the green **Widgets** button (bottom right). The **Widgets** panel
    opens. Drag a widget onto the dashboard, or click **Add** to place it at the
    bottom.

    <Screenshot src="/images/dashboard/widgets-panel.jpg" alt="Widgets panel" caption="① Reset to default layout ② Add ③ Drag handle" />
  </Step>
  <Step>
    ### Reset
    Click **Reset to default layout** in the Widgets panel to go back to the
    standard layout.
  </Step>
</Steps>

Widgets in the panel include **Assigned Customers**, **My Submitted
Approvals**, **Leads**, **Assigned Leads**, and **Leads by Status**. Each one
shows its size (for example *Quarter width · h: 1*).
